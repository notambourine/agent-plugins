# Tell reference

These words are flagged for a second look and are not banned. If the plainer choice
reads worse, keep the original.

| Flagged | Plainer choice |
| --- | --- |
| delve (into) | look at, dig into |
| tapestry, landscape, realm | cut, or name the actual thing |
| underscore, highlight | show |
| leverage (verb) | use |
| seamless, frictionless | easy, or say how |
| robust | reliable, sturdy |
| crucial, pivotal, vital | important, or say why |
| testament to | shows |
| navigate (figurative) | handle |
| foster, cultivate | build |
| elevate, unlock, empower | improve, let |
| myriad, plethora | many, or a number |
| in today's world | cut |
| when it comes to | for |
| it's worth noting | cut |
| at the end of the day | cut |
| that being said | but |
| a double-edged sword | name the specific tradeoff |
| game-changer, revolutionary | say the concrete change |

## Structural tells

- Every paragraph or every sentence is the same length.
- Every section opens with a definition.
- A list where prose would carry the argument better.
- "On one hand, on the other hand" when the author has a view.
- "First, second, finally" in a short passage.
- So much bold that nothing stands out.
- A dash as the default connector.
- A both-sides conclusion to a question the piece already answered.

## Checking a candidate

Ask these in order. If the phrase passes all five, leave it.

1. Does cutting it lose meaning?
2. Is it a formula, or a choice the author would defend?
3. Does it announce a point without making it?
4. Does it add emphasis without adding information?
5. Would a skeptical reader trust the sentence more without it?

## How much to change

Edit a personal piece or a strongly styled author lightly, fixing only clear formula and
vocabulary. Marketing copy has more real tells, so expect more edits there. Keep the
register in both cases: a playful piece stays playful and a white paper stays measured.
